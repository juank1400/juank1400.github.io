Política de privacidad · Finanzas correo

Última actualización: 23 de octubre de 2026.

Quién la usa

Finanzas correo es una herramienta personal. Su único usuario es su autor, Juan Carlos Cepeda Valero, con su propia cuenta de Google.

Qué datos de Google usa

Con el permiso gmail.modify, la herramienta:

  • lee únicamente los correos que tienen la etiqueta Finanzas/entrada;
  • descarga sus archivos adjuntos (PDF y hojas de cálculo);
  • cambia la etiqueta del correo a Finanzas/procesado.

No envía, no borra y no modifica el contenido de ningún correo.

Dónde quedan los datos

Los adjuntos se guardan solo en el computador personal del autor. No se envían a servidores de terceros, no se venden, no se comparten y no se usan para publicidad ni para entrenar modelos de inteligencia artificial. El uso de los datos obtenidos de las API de Google cumple la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Cómo revocar el acceso

El permiso se puede retirar en cualquier momento desde myaccount.google.com/permissions.
